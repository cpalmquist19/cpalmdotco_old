## Notes

- **US-022 shrank.** US-011 and US-012 already built `content/commands.json`, its strict schema (with `icon` and `intro`, D-009 and D-018), the sort by `order`, the duplicate-command check, and the check that every `askAbout` name is a command. What's left is two validation rules, so it drops from 2 points to 1.
- **US-023 grew.** The story's chips need somewhere to put an inline answer before the chat thread exists (US-032), and `history.state` has to carry the thread for Back to work. It is now 5 points. It builds a small conversation provider that US-024 and US-032 reuse, and the minimal `Message`.
- **US-025 now depends on US-023.** The "More" chip belongs in US-023's chip row, and both stories change `HomeHero.tsx`, so the board script would warn.
- **US-029 now depends on US-067.** Both change `lib/content.ts`: US-029 adds `getOffLimits()`, and US-067 changes how its files are read. US-067 first, so the new read is written the way the fix settles on. The fix also keeps the route's runtime reads out of the tracing warning.
- **US-060 now depends on US-023.** Both change `app/globals.css`, and the P3 overlay token waits for the P0 chips, not the other way round.
- **Things found while reading that no story had yet:**
  - The spec says follow-ups come from "related entries" in `commands.json`, but the schema has no `related` field. US-030 has to decide it.
  - `SkipLink` hides itself when `usePathname()` isn't `/`. Next syncs a native `history.pushState` into `usePathname`, so US-023's chip click would hide the skip link while the input is still on screen. US-023 fixes it.
  - The sidebar renders `href={command.answer}`. An `askAbout` command with `answer: "model"` would render `href="model"`. US-024 should add a loader check (F0.2: every sidebar item has an `href`).
  - US-032, when it's scoped, should list US-023 in `depends_on`, because US-023 builds the `Message` component and the conversation provider it extends.
- US-024, US-026 and the S05 stories after US-029 still wait for their own scoping pass.
- **A flake turned up while verifying.** The first `npm run test:e2e` of this story failed once: `[webkit] shell.spec.ts:123 US-005 F0.3: collapsed state survives reload`. This story changes no app code. It's written up as US-073 rather than fixed here, because the cause isn't known and AGENTS.md keeps stories separate.

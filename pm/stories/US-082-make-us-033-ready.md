## Notes

- **Audit result.** The spec's "Chat contract" row says Playwright with a mocked provider. The server side of that is already under test in Vitest: `chat.test.ts` has 26 handler tests for event order, errors, fallbacks, the 500-character cap, the limiter, the timeout and the kill switch. The UI side is 33 e2e tests that stub the page's `fetch`. Only F4.7's `aria-live` attribute was never asserted.
- **What the existing tests can't see.** Both sets stop short of the wire: the route as `next start` serves it, the SDK parsing a real event stream, and a browser reading it. A handler test can't catch a response that Next buffers or an export that is mis-wired. That is the real value of the "mocked provider" row, so US-033 adds a small set of real-route tests and doesn't repeat the rest.
- **The seam.** The Anthropic SDK reads `ANTHROPIC_BASE_URL`, so a fake model API on another port stands in for the provider and the app has no test branch (D-061). Playwright starts `webServer` entries together, so the fake must need no build; it is plain Node.
- **Kill switch.** A second app server with the switch off would need its own build or a launcher, so it is out of scope in US-033, with the reason there. The handler tests and the stubbed `503` e2e tests already cover the switch, and one new route-level test covers the wiring.
- **Points.** US-033 stays at 3: one helper, a config change, six new tests and two single-test additions.

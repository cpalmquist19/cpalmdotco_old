## Notes

- Caleb accepted the recommendation on 2026-10-13: accept the finding and record it as a decision.
- Findings: 5 high-severity, all from GHSA-vfj7-8cjw-p6xm (CVE-2026-93687), a stack-exhaustion denial of service in `braces <= 3.0.3`. No patched version exists; 3.0.3 is the latest release.
- Chain: `eslint-config-next@16.4.0` → `@next/eslint-plugin-next@16.4.0` → `fast-glob@3.3.1` → `micromatch@4.0.8` → `braces@3.0.3`. `micromatch@4.0.8` and `fast-glob@3.3.3` are the latest and still depend on `braces@^3`.
- `npm audit --omit=dev` reports 0 vulnerabilities, so nothing in the shipped site is affected.
- `npm audit fix --force` would install `eslint-config-next@14.2.35`, which is a downgrade from 16.4.0, not an upgrade.
